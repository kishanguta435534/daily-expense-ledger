# Daily Expense Ledger

A small offline expense tracker for recording everyday spending.

## Features
- Add a description, amount, and category
- View the total and number of entries
- Filter by category
- Remove entries
- Store data in browser localStorage

## Run
Open `index.html` in a modern browser. No installation needed.

## Tech
HTML, CSS, JavaScript

This is a learning project, not a banking or financial service.
